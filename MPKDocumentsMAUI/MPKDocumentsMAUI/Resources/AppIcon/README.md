# Иконка приложения

Положите сюда файлы логотипа — после этого пересоберите проект.

## Обязательно

| Файл | Назначение |
|------|------------|
| **`appicon.png`** | Иконка приложения (Android, iOS, Windows, ярлык). Рекомендуется **1024×1024 px**, квадрат, PNG. |

## Для установщика Windows (Inno Setup)

| Файл | Назначение |
|------|------------|
| **`appicon.ico`** | Тот же логотип в формате ICO (можно собрать из PNG на [convertio.co](https://convertio.co/png-ico/) или в GIMP). Нужны размеры 16, 32, 48, 256 px. |

## Опционально

| Файл | Назначение |
|------|------------|
| `Resources/Splash/splash.png` | Картинка на экране загрузки (лучше **512×512** или больше, на тёмном фоне). |
| `MPKDocumentsMAUI.Shared/wwwroot/favicon.png` | Иконка вкладки в веб-версии (32×32 или 64×64). |

## После добавления файлов

```powershell
# Сборка Windows (папка для установщика)
.\installer\build-windows.ps1

# Установщик в Inno Setup Compiler
# Откройте installer\MPKDocuments.iss и нажмите Compile (F9)
```

Пока `appicon.png` нет, используется стандартная заглушка `appicon.svg`.
